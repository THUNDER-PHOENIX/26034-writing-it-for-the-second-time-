# LabelCheck · SIH 2026 prototype

Prototype for Smart India Hackathon Problem Statement 26034: screening packaged commodity labels with OCR, reviewable rule checks, inspection records, and PDF export.

**This is not an official Government of India service or an authoritative legal checker.** OCR may miss or misread small print; verify the complete package and current rules manually. Demo login is not secure authentication.

## Start the app

```powershell
cd frontend
npm install
npm run dev
```

Read [`frontend/README.md`](frontend/README.md) for OCR configuration and storage behavior. The requirement coverage matrix and small-print recovery playbook are in [`docs/problem-statement-26034-audit.md`](docs/problem-statement-26034-audit.md).
